## What You're Ready to Build

### Phase 1: Research Validation (4-6 weeks)

**Goal:** Prove the core hypothesis:
> "Can multi-source evidence reconciliation reduce false negatives compared with single-source verification?"

**What You'll Build:**
- PostgreSQL schema for evidence management
- Normalization engine (SKU, weight, timestamp, size, color)
- Entity resolution (map org-specific IDs to canonical products)
- Synthetic data generator (1000 product lifecycles with injected conflicts)
- Deterministic reconciliation engine (identity + attribute checking)
- Statistical anomaly detection (weight analysis)
- Three baselines (identity-only, weight-only, timeline-only)
- Evaluation & metrics (precision, recall, F1, **false negative reduction**)

**What You Won't Build Yet:**
- React dashboard
- REST APIs
- Authentication
- LLM explanations
- Computer vision
- Production infrastructure

**Success Criteria:**
- Multi-source TriNetra outperforms single-source baselines ✓

- No fabricated data ✓

**Output:** Phase 1 results report showing FN reduction percentage

## Critical Metrics for Phase 1

### Primary Success Metric
```
FALSE NEGATIVE REDUCTION = (FN_Baseline - FN_TriNetra) / FN_Baseline

Example:
Baseline FN Rate: 25%
TriNetra FN Rate: 15%
FN Reduction: (25-15)/25 = 40%

Target: FN reduction > 15% with p-value < 0.05
```

### Secondary Metrics
```
Precision ≥ 0.80  (avoid false accusations against honest customers)
Recall ≥ 0.75     (catch actual conflicts)
F1 ≥ 0.77         (balanced performance)
FPR ≤ 0.15        (don't overload human reviewers)
```
